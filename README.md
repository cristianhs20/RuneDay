# RuneDay

**Level up your real life.**

RuneDay is a cross-platform productivity RPG. Real quests, dailies, habits and focused work power persistent character progression today and will later feed equipment, guilds, raids and seasons.

## Product principle

RuneDay is a productivity product first and an RPG second. The game should make real-world action more satisfying without becoming another distraction.

## Stack

- Laravel 13 / PHP 8.3+
- React 19 + TypeScript
- Inertia 3
- Tailwind CSS 4
- PostgreSQL in production
- Redis planned for queues/cache
- React Native + Expo planned for the mobile client

## Current milestone

Phase 1 — Productivity Core is in active development.

Implemented web flows include:

- Today
- Inbox
- Quests + subtasks
- Campaigns/projects
- Dailies
- Habits
- Focus timer
- Calendar
- XP/gold reward ledger
- provisional anti-farming controls

See [docs/phase-1.md](docs/phase-1.md) for the detailed status and remaining scope.

## Local setup

```bash
composer run setup
composer run dev
```

The project uses Laravel Wayfinder. Route/action TypeScript helpers are generated by Artisan/Vite and must exist before the global TypeScript check.

## Quality checks

```bash
npm run check
npm run types:check
vendor/bin/pint --test
php artisan test
```

GitHub Actions installs PHP/Node, runs migrations, builds the frontend to generate Wayfinder helpers, and executes the complete suite.

## Core rule

Productivity modules never mutate balances directly. XP, currencies and future competitive rewards flow through the Game domain and are recorded with a traceable source.
