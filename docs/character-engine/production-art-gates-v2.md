# RuneDay Production Art Gates v2

## Gate D1 — Sprite standard

Approve before runtime asset production:

- 128×128 cell;
- PNG transparency;
- layer order;
- fit profiles;
- manifest schema;
- naming.

## Gate D2 — Human Broad static master

Required:

- Front;
- Side;
- Back;
- Base Hero;
- face;
- eyes;
- hair;
- starter equipment.

Review against approved concept board.

Do not proceed when the result is merely “better than SVG.”

It must be visually desirable.

## Gate D3 — Human Broad renderer integration

Required:

- manifest loader;
- layer composition;
- integer scaling;
- debug layer list;
- missing-asset fallback.

## Gate D4 — Human Broad authored motion

Required:

- Idle;
- Walk;
- Attack;
- Cast;
- Celebrate;
- Hurt.

Review:

- naked/base;
- starter;
- prestige benchmark.

## Gate D5 — Human Lean

Must reach the same quality as Human Broad.

## Gate D6 — Elf

Required:

- Broad;
- Lean;
- ears;
- faces;
- hair;
- starter benchmark.

## Gate D7 — Skeleton

Required:

- Broad;
- Lean;
- skulls;
- bones;
- jaw;
- soul eyes;
- starter benchmark.

## Gate D8 — Ogre

Required:

- Heavy;
- face;
- ears;
- tusks;
- horns;
- heavy fit profile.

## Gate D9 — Equipment benchmark

Benchmark items across required fit profiles.

No mass catalog yet.

## Gate D10 — Product cutover

Required surfaces:

- Hero;
- Today;
- Inventory;
- Shop;
- Adventure;
- Friends;
- public profile;
- Guilds;
- share cards.

After D10:

- SVG prototype renderer is removed from user-facing product surfaces;
- Sprite Engine v2 becomes canonical.
